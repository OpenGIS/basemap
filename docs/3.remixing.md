# Remixing the Style

> How to modify the style, rebuild and republish.

## Where to Edit

The style is defined by the vendored OpenMapTiles sources under `vendor/openmaptiles/`:

- **Layer styles**: `vendor/openmaptiles/layers/*/style.json` — 16 layer directories (aerodrome_label, aeroway, boundary, building, housenumber, landcover, landuse, mountain_peak, park, place, poi, transportation, transportation_name, water, water_name, waterway).
- **Style header**: `vendor/openmaptiles/style/style-header.json` — name, centre, zoom, bearing, pitch, background layer and the source/glyphs/sprite defaults (these are overridden by the build's jq rewrite).
- **Icons**: `vendor/openmaptiles/style/icons/*.svg` — the 306 source SVGs used to build the sprite sheets.

## Rebuild

```bash
./scripts/build.sh
```

This regenerates `style.json`, the sprite sheets, `icons/` and the merged `fonts/` directories at the repository root. See [2.build.md](2.build.md) for what happens in detail.

## Republish

The repository root is served by GitHub Pages. Commit the regenerated artifacts and push to `master` — the Pages deployment picks them up automatically.

> [!WARNING]
> **Keep the attribution** — the OpenFreeMap / © OpenMapTiles / OpenStreetMap attribution is a licence requirement (CC-BY-4.0 design, ODbL data). The build bakes it in; don't remove it.

## Notes

- `build/` is gitignored intermediate output — never commit it.
- Fonts are only regenerated for stacks actually referenced by `style.json`; the merge script derives the stack list from the style's symbol layers.
- If you add a new font, place its 256-range PBFs in a directory under `fonts/` named after the font, and reference it from a layer's `text-font` array.
