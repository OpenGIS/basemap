# Getting Started

> What Basemap is, where it is published, and how the repository is laid out.

## What This Is

Basemap is a self-hosted [MapLibre GL](https://maplibre.org) style. It vendors the OpenMapTiles "OSM" vector style (v3.16 — the vector equivalent of the official openstreetmap-carto raster) and repoints it at OpenFreeMap's worldwide, free OpenMapTiles-schema vector tiles. All fonts, sprites and icons are self-hosted on GitHub Pages with open CORS, so anyone can use the style or its assets directly.

The repository is one root Nuxt site with a single consumer-facing route: the full-screen basemap and live palette inspector at `/`. It runs client-side from the Nuxt project under the `/basemap/` base path. The editable palette is [`palette.json`](../palette.json); the app source is [`app/`](../app/). There is no root `index.html` and no pre-built palette output in the repository; the site is generated from `app/` into `.output/public`, which is not committed.

## Quick Start

Open the [map and palette inspector](https://www.ogis.org/basemap/), or load the style in any MapLibre GL application:

```js
const map = new maplibregl.Map({
  container: 'map',
  style: 'https://www.ogis.org/basemap/style.json'
});
```

The homepage ([`app/pages/index.vue`](../app/pages/index.vue)) is a full-screen MapLibre GL map that opens at London Paddington (`51.5154, -0.1755`) at zoom 17. MapLibre GL is installed from npm and bundled with the site rather than loaded from a CDN. A compact overlay carries the Open GIS brand, the `Basemap` title, an **Inspect POIs** toggle, an **Export palette** button and a live camera readout. Inspecting a POI opens an inspector with its icon preview, name, class/subclass, layer, palette role, colour picker, hex field and role reset.

Camera state is encoded in an OSM-style URL hash, `#map=zoom/lat/lng/pitch/bearing`, matching www.ogis.app. Query parameters remain for `width`, `height`, `style` and `quality`; the legacy query map parameters (`lat`, `lng`, `zoom`, `pitch`, `rotation`) are accepted as a fallback when the hash is absent. Camera moves are written back with `history.replaceState`, and a `hashchange` event jumps the map to the new state. The readout in the overlay shows the current centre, zoom, pitch and bearing, synced on every `move`. See [4.screenshots.md](4.screenshots.md) for the full URL API and the automation signals the page exposes.

For local development:

```bash
npm install
npm run dev
```

The dev server runs at <http://127.0.0.1:11100/basemap/>. Install the Playwright Chromium binary for screenshots and the end-to-end suite:

```bash
npx playwright install chromium
```

Run the Node suite with `npm test`. The Playwright smoke suite needs a built site and the Chromium binary:

```bash
npm test                # Node suite, no browser
npm run test:e2e:build  # build the site, then run the Playwright smoke suite
```

`npm run test:e2e` runs the same suite without rebuilding, against an existing `.output/public`. The test server serves it at <http://127.0.0.1:11101/basemap/>. See [4.screenshots.md](4.screenshots.md) for the harness and [6.site.md](6.site.md) for CI and Pages.

## Published URLs

All URLs use the org's GitHub Pages custom domain **www.ogis.org** directly.

> [!WARNING]
> Never use the org's legacy `*.github.io` Pages host — it 301-redirects to www.ogis.org, and the redirect hop breaks CORS in browsers.

| Asset | URL |
| --- | --- |
| Demo | https://www.ogis.org/basemap/ |
| Style | https://www.ogis.org/basemap/style.json |
| Glyphs | https://www.ogis.org/basemap/fonts/{fontstack}/{range}.pbf |
| Sprite | https://www.ogis.org/basemap/sprite |
| Icons | https://www.ogis.org/basemap/icons/{name}.svg |
| Tiles | https://tiles.openfreemap.org/planet |

The published style is named "Basemap", is version 8, and contains the full OSM layer set. The tiles source is OpenFreeMap's TileJSON at https://tiles.openfreemap.org/planet (OpenMapTiles schema v3.16.0, maxzoom 14, free, no API key, CORS-open).

The Pages site contains only the homepage map, its overlay and assets. The technical documentation under `docs/` stays in the repository and is not deployed.

## Fonts

MapLibre GL requests glyphs with the `text-font` array joined by commas as the `{fontstack}` URL segment. GitHub Pages is static, so comma-joined stacks are pre-merged into single directories at build time — first font wins per glyph, with missing glyphs filled from subsequent fonts (e.g. CJK flows from Noto Sans). See [2.build.md](2.build.md) for how this works.
